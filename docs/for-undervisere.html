For undervisere

Bruk kurset som undervisningsopplegg, seminargrunnlag eller faglig støtte.

Materialet er laget slik at det kan brukes fleksibelt: som selvstudium, som del av et kursforløp, eller som støtte i mindre grupper som vil utforske AI i helse sammen.

Bruk i undervisning

Tre enkle måter å bruke materialet på

Som komplett kursløp

Bruk uke 1-8 som en gradvis progresjon fra begreper og modellforståelse til klinisk anvendelse, etikk og implementering.

Som modulbasert undervisning

Velg ut enkelte uker, for eksempel generativ AI, klinisk praksis eller etikk, og bruk dem som egne temaøkter.

Som refleksjonsgrunnlag

Bruk README-er og utvalgte notebooks som felles utgangspunkt for diskusjon, refleksjon og faglig orientering.

Anbefalt oppstart

Et enkelt opplegg for første gang

  1. Start med forsiden og `Start her` for å velge riktig inngang for målgruppen din.
  2. Bruk `Uke 1` som felles introduksjon hvis deltakerne har ulik bakgrunn.
  3. Velg deretter temauker som passer formålet: `Uke 4` for generativ AI, `Uke 6` for klinisk praksis, `Uke 8` for etikk og innføring.

Lav terskel for deltakere

Mange deltakere vil ha godt utbytte av å lese og diskutere materialet uten å kjøre all kode selv. Notebookene kan derfor brukes både som interaktive øvelser og som lesbare fagtekster.
