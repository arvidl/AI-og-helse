# Hvordan bidra

Takk for at du vil bidra til `AI-og-helse`.

Dette repoet er laget som åpent kursmateriale for norskspråklige studenter og fagpersoner i helse. Bidrag som forbedrer faglig kvalitet, språk, pedagogikk, kodeeksempler og dokumentasjon er velkomne.

## Hva slags bidrag passer godt?

- rette skrivefeil, døde lenker og uklar dokumentasjon
- forbedre notebook-forklaringer, oppgaver og visualiseringer
- gjøre Colab- eller lokal kjøring enklere og mer robust
- rydde opp i notebook-metadata når endringen er bevisst og konsekvent
- foreslå nye faglige eksempler eller relevante ressurser

## Før du sender meg forslag til endringer / issues

- sjekk at endringen passer med kursnivået og målgruppen
- hold språk og tone på norsk der materialet er studentrettet
- unngå å committe hemmeligheter som API-nøkler, `.env`-filer eller `kaggle.json`
- unngå utilsiktet notebook-støy som endrede execution counts, output eller lokal metadata hvis det ikke er meningen

## Issues og forslag

Bruk gjerne [GitHub Issues](https://github.com/arvidl/AI-og-helse/issues) for å:

- rapportere feil
- foreslå forbedringer
- melde fra om utdaterte lenker eller dokumentasjon
- beskrive problemer med Colab, datasett eller API-oppsett

## Notebooks og metadata

Ved endringer i `.ipynb`-filer er det spesielt nyttig å skille mellom:

- faglige/pedagogiske endringer
- output-endringer etter kjøring
- rene metadataendringer
